# 名探偵〇〇 ― 無料で遊べるブラウザ推理ミステリーゲーム

**▶ 今すぐ遊ぶ：https://mtvmtvmtv2021-qaz.github.io/meitantei/**

登録・ダウンロード不要、無料で遊べるドット絵の探偵アドベンチャー（ミステリーゲーム／推理ゲーム／謎解きゲーム）です。

2Dドット絵の探索型ミステリーアドベンチャーです。主人公は少し名の知れた俳優。撮影現場や仕事先で事件に巻き込まれ、助手と一緒に証拠を集め、証言の矛盾を突き、「あなたが犯人だ！」と犯人を告発します。

## 遊び方（起動方法）

- **`index.html` をブラウザで開くだけで遊べます。** インストールやサーバーは不要です。
- `index.html` と `css/`・`js/` フォルダは、同じ場所に置いたままにしてください。
- GitHub Pages で公開する場合は、このフォルダをそのままリポジトリに置き、Pages を有効にします。
- 推奨ブラウザ：Chrome、Edge、Firefox、Safari の最新版（PC）
- 最初にキーを押すかクリックすると、音（BGM・効果音）が鳴り始めます。

## 操作方法

| キー | 操作 |
|---|---|
| 矢印キー／WASD | 移動・カーソル移動 |
| Z／Enter／Space | 決定・調べる・話す・会話を進める |
| X／Esc | 戻る・キャンセル（探索中はメニュー） |
| I | 持ち物・証拠品（証言中は「証拠を見せる」） |
| M | メニュー（人物図鑑・事件ファイル・セーブ・ロード・設定） |
| C | 助手に相談（隠し場所の発見・ヒント）／証拠品画面では組み合わせ |
| F | 「あなたが犯人だ！」で告発する |
| A | 証拠品画面で、AIロボットに分析させる（助手がロボットのとき） |

画面下のボタンをクリックしても操作できます。

## 収録内容

- 第1事件「消えた銀時計」：山奥の洋館での、密室風の盗難事件
- 第2事件「消えた子役」：古いホテルでの誘拐事件
- 第3事件「最後の台本」：閉鎖されたテレビ局での殺人事件
- 第2章（第3事件のエンディングのあとに続きます）
  - 第4事件「笑う楽屋の幽霊」：浅草の演芸場でのコメディ・ミステリー
  - 第5事件「真夜中の霊安室」：廃病院ロケ地でのホラー・ミステリー
  - 第6事件「消えた結婚指輪」：マネージャーの結婚式での人間ドラマ
  - 第7事件「雪原に消えた足あと」：雪山のロッジでの足あとの謎
  - 第8事件「授賞式のラストシーン」：映画祭の授賞式での第2章フィナーレ

## セーブ

- オートセーブ1枠と手動セーブ3枠があります。データはブラウザ（localStorage）に保存されます。
- セーブデータが壊れていても、ゲームは起動できます。手動セーブ枠は、バックアップからの自動復元も試みます。

## ファイル構成

```
index.html      … 起動ファイル（ゲーム画面と紹介文）
style.css       … 画面デザイン
core.js         … 状態・条件判定・セーブ
art.js          … ドット絵の生成（キャラ・立ち絵・タイル・アイコン）
audio.js        … 自作チップチューンBGM・効果音
ui.js           … 会話・メニュー・証拠品・人物図鑑・事件ファイル
explore.js      … マップ探索・調査・会話の4行動
trial.js        … 証言・証拠提示・告発・事件評価
story.js        … タイトル・主人公設定・幕間・エンディング
main.js         … 起動・入力・メインループ
case1〜8.js, hidden.js … 事件ごとのデータ
ogp.png・robots.txt・sitemap.xml … 検索・SNS向けのファイル
```

新しい事件を追加するときは、事件ファイルを追加して、`index.html` に読み込む行を足し、`core.js` の `G.ORDER` に登録します。
画像・音声ファイルは使っていません。ドット絵と音はすべてプログラムで生成したオリジナルです。
